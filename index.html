MIROS v1.0

ESP32-C3 0.42" OLED Smart Platform

A feature-packed micro operating system engineered for ultra-compact ESP32-C3 development boards with integrated 72x40 SSD1306 displays. Operates smoothly via a unified single-button gesture machine.

MCU: ESP32-C3 RISC-V @ 160MHz
Display: 0.42" OLED (72x40 SSD1306 I2C)
Input: Single Button (BOOT)
Indicator: Status LED (GPIO 8)
Storage: Preferences NVS Flash

Hardware Architecture & Energy Management

Designed specifically for low-power operation and long display lifespan.

⚡ Auto-Dim System

To protect the 0.42" OLED screen from burn-in, MIROS automatically monitors button inactivity (`lastActivity`). After 30 seconds of idle time, display contrast drops from 255 down to 30.

💤 Bouncing Screensaver

If inactivity continues for 45 seconds total (30s dim + 15s delay), MIROS enters screensaver mode, bouncing a low-brightness "MIROS" emblem across the screen. Pressing the BOOT Button wakes the screen seamlessly.

💾 EEPROM / Preferences NVS

Uses ESP32 non-volatile storage to persist user data. All game high scores (`snk_hi`, `flp_hi`, `png_hi`, `spc_hi`, `dno_hi`) and tally counter state survive complete battery disconnects.

Flash MIROS to your board

Installs straight from your browser. Takes about 30 seconds, nothing to download.

  1. Use Google Chrome on a computer Chrome or Edge on Windows, macOS, Linux or ChromeOS. Firefox, Safari and phones can't flash.
  2. Plug in your board Use a USB-C data cable (charge-only cables won't show a port). Plug it straight into the computer.
  3. Click “Connect & Install” below Chrome opens a small popup listing the available serial (COM) ports.
  4. Pick your board's port, then press Connect Look for USB JTAG/serial debug unit (or CH340 / CP210x on some boards). Ignore Bluetooth ports.
  5. Press Install and wait for 100% Tick Erase device for a clean install (this also clears saved high scores). Don't unplug while it flashes.
  6. Press RST (or replug) MIROS boots and the menu appears on the OLED. Tap BOOT to scroll, hold 0.7s to open an app.

Port not showing up or flashing fails?
  • Empty port list: swap the cable (it must carry data) and try another USB port.
  • Enter download mode: hold BOOT, tap RST (or plug in while holding BOOT), release BOOT, then click Connect again.
  • “Failed to connect” or port busy: close anything else using the board (Arduino or PlatformIO serial monitor, other flasher tabs).
  • Windows with CH340 or CP210x boards: install the matching USB-serial driver, then replug.
  • Linux: run sudo usermod -aG dialout $USER, then log out and back in.
  • Stuck on boot after flashing: flash again with Erase device ticked.
